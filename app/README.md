E-Commerce Store

This is an e-commerce website which contains all the expensive electronic products built using **Node.js**, **React**, and **Tailwind CSS** with SQL database support.

Features 

**User Authentication** — Register, login, and maintain session state  
**Product Management** — View available products by category  
**Wishlist Page** — Save products for future purchase  
**Cart System** — Add, remove, and update quantities in your cart  
**Order Management** — Place and view your orders  
**Responsive UI** — Fully responsive for desktop and mobile  
**Optimized with Node.js 16 and Tailwind CSS**

Tech Stack

- **Frontend:** Next.js (React), JavaScript, Tailwind CSS  
- **Database:** SQL / H2 Database  
- **Backend:** Next.js API Routes  
- **Tools:** Git, Vercel (for deployment) 

Installation

```bash
git clone https://github.com/Jayanth2005609/Shopping-Website.git
cd Shopping-Website
npm install
npm run dev

## how to use 

Open http://localhost:3000

Register a new user account or log in.

Browse the product list.

Add products to wishlist or cart.

Proceed to place an order.
